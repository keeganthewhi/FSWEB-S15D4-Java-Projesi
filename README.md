# Stacks & Queues

> Full Stack Web Development Bootcamp — Sprint 15, Day 4

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

## About

Explores stack and queue data structures in Java, covering LIFO and FIFO access patterns. This assignment demonstrates practical use cases for these fundamental data structures.

## Key Concepts

- `Stack` class and LIFO operations (push, pop, peek)
- `Queue` interface and FIFO operations (offer, poll, peek)
- `Deque` and `LinkedList` as queue implementations
- Real-world applications of stacks and queues
